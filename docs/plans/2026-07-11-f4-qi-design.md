O QI ("Quem Indica") é o programa de indicações com cashback: o usuário compartilha um código (`QI-XXXX-XXXX`), acompanha indicados, ganhos e nível (Bronze/Ouro), e saca o saldo via Pix. Substitui integralmente o sistema de referral existente.

## 4. Serviço — `QiService`

Interface em `lib/services/types.ts`; mock em `lib/services/mock/mockQiService.ts` + `lib/services/mock/qiFixtures.ts`; exposto via `context/ServicesContext.tsx` (padrão F1/F3). Valores em **centavos (int)**.

```ts
interface QiSummary {
  balanceCents: number;        // "Saldo Cashback" do hero
  totalEarnedCents: number;    // "Lucro total"
  indicadosCount: number;
  bonusCount: number;
  level: string | null;        // nível atual (null = nenhum)
  nextLevel: { name: string; target: number } | null; // "Indique 5 para Bronze" / "30 para Ouro"
}

interface QiIndicacao {
  id: string;
  name: string;
  avatarUrl: string | null;
  earnedCents: number;         // "Você ganhou"
  status: 'active' | 'inactive';
  indicatedAt: string;         // "Indicada em"
  firstAppointmentAt: string | null;
  lastActivityAt: string | null;
  appointmentsCount: number;
}

interface QiStatementEntry {   // extrato da tela de detalhes
  id: string;
  title: string;               // "Agendamento realizado"
  subtitle: string;            // nome do cliente do agendamento
  date: string;
  amountCents: number;
}

interface QiProgramRules {     // conteúdo do "Como funciona" — nada hardcoded em tela
  perServicePct: number;       // 10
  monthlyBonusCents: number;   // +R$ 5
  topLevelMultiplier: number;  // x2 (Ouro)
  minWithdrawCents: number;    // R$ 30
  feeCents: number;            // R$ 5
  feeFreeThresholdCents: number; // R$ 200
  creditWindowHours: number;   // 24
}

interface WithdrawQuote { feeCents: number; totalCents: number; etaLabel: string }

interface QiService {
  getQiSummary(): Promise<QiSummary>;
  getQiCode(): Promise<string>;                       // "QI-HOG23-3892"
  listIndicacoes(page: number): Promise<{ items: QiIndicacao[]; totalPages: number }>;
  getIndicacao(id: string): Promise<QiIndicacao>;
  getIndicacaoStatement(id: string): Promise<QiStatementEntry[]>;
  getProgramRules(): Promise<QiProgramRules>;
  quoteWithdraw(amountCents: number): Promise<WithdrawQuote>;
  requestQiWithdraw(amountCents: number, pixKeyId: string): Promise<void>; // debita o saldo mock
}
```

Chaves Pix: o QI **reusa `WalletService.getPixKeys`/`addPixKey`** — mesma chave da carteira/financeiro, sem duplicação.

Mock: fixtures espelhando o Figma (cliente: 12 indicados/pessoas, saldo R$ 74,09; lojista: indicadas/negócios, saldo R$ 89,09); estado vazio alcançável para o QI-blank; compartilhamento via `Share` nativo; latência com `delay()` como no `MockWalletService`.

## 5. Rotas, componentes e navegação

**Rotas** (espelhadas nos 2 lados):

```
app/(client)/qi/index.tsx            # cheio/vazio pela mesma tela
app/(client)/qi/indicacao/[id].tsx   # detalhes + extrato
app/(client)/qi/how-it-works.tsx
app/(client)/qi/withdraw.tsx
app/(client)/qi/new-pix-key.tsx      # wrapper do PixKeyForm (como financeiro/new-pix-key)
app/(merchant)/qi/...                # mesmo conjunto
```

**Componentes compartilhados** em `components/qi/` (parametrizados por props; rotas finas passam textos/serviço):
- `QiEarningsCard` — "Ganhos por indicação": lucro/indicados/bônus + barra de progresso de nível + chip "Top Indicações"
- `QiCodeCard` — código copiável/compartilhável com subtítulo por lado
- `QiIndicadosList` — lista paginada (paginação numerada do Figma) com linha avatar/nome/"Você ganhou"
- `QiStatementList` — extrato da tela de detalhes (timeline verde)

**Withdraw compartilhado**: novo `components/wallet/WithdrawFlow.tsx` com o layout 🆕 — hero saldo → input em centavos + chips R$ 50/R$ 100/Tudo → seleção de chave Pix (`PixKeySection`) → **Resumo da transferência** (valor, taxa de operação, tempo estimado, total a receber) → banner de isenção (> R$ 200) → confirmar → overlay de loading → modal de sucesso. Props: `balanceCents`, chaves Pix, `quote()`, `onConfirm()`, rota de nova chave e textos. Usado pelos 2 withdraws do QI **e** pelo `app/(merchant)/financeiro/withdraw.tsx` (refatorado; `MockWalletService` ganha `quoteWithdraw`).

**Navegação**: item "QI" nos `drawerItems` das telas com drawer dos 2 lados (home, wallet/financeiro, aqui-agora); entradas "Indicações" dos settings apontam para `/qi`; `_layout.tsx` dos grupos ganham as rotas novas se necessário.
